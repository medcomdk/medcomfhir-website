This page provides a list of the FHIR artifacts defined as part of this implementation guide.

Terminology: Value Sets

These define sets of codes used by systems conforming to this implementation guide.

DK XDS ClassCode

Value set for the classCode attribute. classCode used in DK IHE Document sharing
DK XDS ConfidentialityCode

Confidentiality code used in Danish Document sharing.
DK XDS EventCodeLists

ValueSet containing EventCodeLists.
DK XDS FormatCode

ValueSet containing FormatCode.
DK XDS HealthcareFacilityTypeCode

Value set for healthcare facility type code represents the type of organizational setting of the clinical encounter during which the documented act occurred.
DK XDS HomeCommunityId

List of operational and in production home communities (XCA) in Danish Document Sharing
DK XDS LanguageCode

Tags for the Identification of Languages (RFC 3066)
DK XDS MimeType for FHIR documents

Values for the document metadata attribute mimeType
DK XDS MimeType for non-FHIR XML documents

Values for the document metadata attribute mimeType
DK XDS PracticeSettingCode

Values used for the document metadata attribute practiceSettingCode, which is an attribute specifying the clinical specialty where the act that resulted in the document was performed (e.g., Family Practice, Laboratory, Radiology). The value set is based on a subset of the code list from the SOR lookup table 'SOR-Kliniske specialer' (https://sor.sum.dsdn.dk/lookupdata/#clinical_speciality, accessable on Sundhedsdatanettet (SDN)), which is based on SNOMED codes.
DK XDS TypeCode ValueSet

ValueSet containing TypeCode.
