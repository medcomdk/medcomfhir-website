# Extensions - DK MedCom Core v1.0.0-test

## Extensions

The following extensions are defined in DK MedCom Core.

* [ContactExtension](StructureDefinition-medcom-core-contact-extension.md) 
Extension that contains the contact information 

* [DateTimeExtension](StructureDefinition-medcom-core-datetime-extension.md) 
Date and time of this payload 

* [IdentifierExtension](StructureDefinition-medcom-core-identifier-extension.md) 
An extension holding a specific identifier datatype 

* [PractitionerExtension](StructureDefinition-medcom-core-practitioner-extension.md) 
Reference to a PractitionerRole and subsequent Practitioner 

* [SenderExtension](StructureDefinition-medcom-core-sender-extension.md) 
Reference to a more specfic sender of a message. 

* [MedCom Observation ValueAttachment Extension](StructureDefinition-medcom-observation-value-attachment-extension.md) 
Generic extension for Observation value as Attachment type.
