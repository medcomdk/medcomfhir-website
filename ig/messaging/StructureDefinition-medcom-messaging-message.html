Resource Profile: MedComMessagingMessage

Official URL: http://medcomfhir.dk/ig/messaging/StructureDefinition/medcom-messaging-message Version: 4.0.3
Active as of 2026-11-11 Computable Name: MedComMessagingMessage

Base resource for all MedCom messages.

Scope and usage

MedComMessagingMessage is the common Bundle profile used by MedCom messaging standards. Individual standards specialize it for their clinical content and corresponding MessageHeader profile. The snapshot and constraints below define the required structure.

Additional governance

The following requirements are not expressed as constraints on this Bundle profile.

ID Requirement
MSG-04 A MedCom FHIR Message SHALL contain at least two bundled MedComMessagingOrganization resources.
MSG-10 With the exception of an acknowledgement message; A MedCom FHIR Message SHALL contain at least one bundled MedComCorePatient resource.

Validation before dispatch and before processing received messages is governed by Messaging validation governance.

Bundle identifiers and dispatch time

Bundle.id corresponds to the EnvelopeId in MedCom OIOXML messages. Each time a message is dispatched, the sender SHALL assign a new globally unique Bundle.id; it SHALL NOT reuse the id of a previously dispatched Bundle. A new Bundle.id does not change the identity of the message carried in the Bundle; see MessageHeader identity.

The optional Bundle.identifier can be assigned explicitly by the sending application and MAY have the same value as Bundle.id.

Bundle.timestamp records the dispatch time of the message. See Provenance timestamps for the sending activity's timestamps and reliable messaging for retry handling.
